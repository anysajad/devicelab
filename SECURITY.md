# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability within DeviceLab, please send an email to the project maintainer. All security vulnerabilities will be promptly addressed.

Please do not report security vulnerabilities through public GitHub issues.

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | Yes       |

## Security Best Practices

When using DeviceLab, please ensure:

- You are running the latest version
- Your development environment is secure
- You are not exposing the application to untrusted networks in production

## Disclosure Policy

When the security team receives a security bug report, they will assign it to a
primary handler. This person will coordinate the fix and release process.
